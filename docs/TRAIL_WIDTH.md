## Read-out

- **Tight trails (5–10%)** get whipsawed out of winners early: many more trades, lower win rate, and usually lower CAGR — the ratchet fires on normal weekly noise.
- **Wider trails (15–20%)** give winners room to run (fewer trades, higher win rate), so CAGR is higher; drawdown is a bit deeper because you give back more before exiting.
- Pick the width where CAGR is strong and drawdown is still tolerable — usually 15–20% for this weekly, small/mid-cap breakout system.
